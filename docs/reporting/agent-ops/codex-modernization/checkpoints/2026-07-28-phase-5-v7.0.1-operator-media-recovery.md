## Release Scope

`v7.0.1` is a patch to the stable local/demo software baseline. It preserves
model artifacts during upload conflicts, replaces the retired Quit control with
the typed restart action, aligns routine video badges with OSD visibility, and
gives WebRTC negotiation stages independent bounded deadlines.

The release also replaces active PixEagle guidance for the former broad QGC
draft with the focused generic QGC sequence:

- #14727: redact stream URLs in QGC diagnostics
- #14728: preserve Windows software-decoded frames
- #14729: make the local HTTP test fixture deterministic
- #14730: add unauthenticated HTTP MJPEG reception
- #14731: add unauthenticated WebSocket JPEG reception

Authorization headers, Origin configuration, custom CA storage, token
management, and recording policy are not hidden in the transport changes. They
remain separate security and lifecycle work.

## Runtime Restart Finding

The running lab process was started before the manual-restart correction while
its dashboard files were updated in place. Its authenticated runtime status
therefore returned `no_pending_system_restart_changes`. Current source permits
a confirmed manual restart without pending config from the maintained manual,
browser-lab, and managed-service launchers. Active Following or Offboard,
missing administrator authorization, unavailable safety state, and unavailable
durable audit remain intentional blockers.

An old backend cannot adopt that behavior without one host-side stop/start. The
dashboard now reports that exact mixed-generation condition instead of the
generic unavailable-runtime message. No live process was stopped or restarted
while collecting this evidence.

## Evidence Boundaries

Integrated QGC candidates rendered HTTP MJPEG and WebSocket JPEG on Linux,
Windows, and Android. Windows also reproduced and cleared the green-frame
failure through the focused system-memory correction. Upstream review and CI
remain the authority for merge readiness; macOS and iOS were not manually
tested.

This checkpoint does not prove public WebRTC media reachability, TURN
configuration, Raspberry Pi or Jetson performance, NCNN acceleration, PX4 or
Pixhawk response, SIH/SITL/HIL behavior, real camera/gimbal operation, field
safety, aircraft operation, or regulatory compliance.
