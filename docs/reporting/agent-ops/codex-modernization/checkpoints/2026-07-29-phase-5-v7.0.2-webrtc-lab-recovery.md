## Release Scope

`v7.0.2` closes the same-host browser fallback from WebRTC to WebSocket.
The dashboard now keeps the ICE/media deadline active when `ontrack` arrives
before ICE connects. The decoded-frame deadline begins only after both a remote
video track and ICE `connected`/`completed` exist. It sends the canonical local
SDP and handles streamless remote tracks.

The server treats a client disconnect during answer delivery as normal peer
cleanup. It does not report a negotiation fault or attempt a second write to a
closed signaling socket.

The explicit beginner browser lab can open the Linux kernel UDP ephemeral range
used by aiortc together with TCP `3040` and `5077`. Private rules remain
source-scoped, and public HTTP still requires explicit consent. Newly created
UFW rules receive unique comments recorded in an owner-only receipt. Setup
rollback and cleanup remove only those exact rules; pre-existing operator rules
on the same ports are preserved.

## Evidence Boundaries

This checkpoint proves the local authenticated browser-lab WebRTC path and
simulated ownership-safe host-firewall transactions. It does not prove public
NAT traversal, provider-firewall reachability, TURN, production TLS/WSS,
Raspberry Pi or Jetson performance, PX4/Pixhawk response, SIH/SITL/HIL,
camera/gimbal operation, field safety, aircraft operation, or regulatory
compliance.

Production remote WebRTC remains under PXE-0103 and requires bounded relay and
firewall ownership, short-lived TURN credentials, HTTPS/WSS, and retained
receiver evidence.

## Superseding Evidence

After release, a remote browser completed signaling and received a video track,
but ICE remained `connecting` until Auto correctly fell back to WebSocket. The
host had active default-deny UFW with TCP `3040`/`5077` allowed and no aiortc
UDP candidate-range rule. The release smoke had not traversed that firewall.
PXE-0150 owns the host-rule reconciliation, exact remote decoded-frame gate,
and a separate reset/dashboard CORS and build-cache regression found during the
same acceptance pass.
