# September 2026 Journal

## 2026-09-19 - PXE-0171 Automatic Raspberry Pi CSI Selection

- Implemented `CSI_RPI: auto`: direct BGR, then NV12 conversion after an open
  or first-frame failure. Reuses the source recovery loop, probe, timeout and
  diagnostics; failed candidates are released before opening another.
- Explicit templates, Jetson and other source types keep their existing path.
  Existing installs adopt auto explicitly through Settings/Config Sync.
- See [implementation checkpoint](../checkpoints/2026-09-19-csi-auto-capture.md)
  for validation and remaining physical-camera evidence.

## 2026-09-15 - PXE-0171 Raspberry Pi CSI GStreamer Reconciliation

- Compute Module testing found a camera visible to `rpicam-hello` while
  GStreamer lacked `libcamerasrc`.
- The optional OpenCV/GStreamer path now reconciles the small platform plugin
  separately, so a compatible source-built OpenCV provider remains reusable.
- CSI initialization reports the missing OpenCV capability or source element
  directly through media health. Current Pi OS Lite checks no longer depend on
  a visible preview in an SSH session.
- Follow-up IMX219 evidence in GitHub issue #19 showed that an available source
  could still fail ambiguous caps negotiation. The Pi default now requests
  processed `NV12` explicitly before converting to OpenCV BGR.
- Physical camera-frame validation remains pending on the tester's board.

## 2026-09-17 - PXE-0171 Direct BGR Benchmark Assessment

- Reviewed the operator-supplied standalone and PixEagle CSVs: direct BGR saves
  substantial process CPU at equal 720p30 throughput and restores standalone
  1080p30 throughput. No general memory or GPU penalty is established.
- Documented the working CM5/IMX219 override and corrected stale camera-guide
  hardware acceleration claims. Runtime defaults remain unchanged in this slice.
- Recorded failed 60 FPS modes, misleading empty harness error fields, CPU
  accounting limits, and follow-up requirements in
  [the assessment](../checkpoints/2026-09-17-csi-bgr-benchmark-assessment.md).
- Recommended a subsequent BGR-preferred stock Pi path with bounded NV12
  fallback; explicit operator pipelines remain authoritative.
